# Бібліотека фільмів

Це веб-застосунок для перегляду та управління колекцією фільмів. Користувачі можуть реєструватися, входити через Google, додавати фільми до улюблених та переглянутих, а також переглядати подробиці фільмів.

## Опис

Проєкт надає інтерфейс для:

- Реєстрації користувачів через Firebase Auth з використанням Google.
- Збереження даних про користувача та його фільми в Firebase Realtime Database.
- Перегляду фільмів, додавання їх до улюблених або переглянутих, з автоматичним оновленням даних у Firebase і Redux.
- Відображення подробиць фільмів і подібних фільмів.

## Технології

- **React**: для розробки інтерфейсу.
- **Redux**: для керування станом додатку.
- **Firebase**: для аутентифікації та зберігання даних (Firebase Auth і Realtime Database).
- **Firebase Realtime Database**: для зберігання даних про фільми.
- **React Router**: для маршрутизації між сторінками.
- **CSS/SCSS**: для стилізації інтерфейсу.
- **Axios**: для запитів до зовнішнього API для отримання інформації про фільми.

## Функціональність

- **Аутентифікація через Google**: користувач може увійти за допомогою облікового запису Google.
- **Реєстрація та профіль**: після реєстрації користувач може переглядати свої улюблені та переглянуті фільми.
- **Перегляд фільмів**: кожен фільм містить деталі, такі як назва, опис, рейтинг і подібні фільми.
- **Управління улюбленими та переглянутими фільмами**: користувач може додавати фільми до своїх улюблених чи переглянутих, і ці зміни автоматично відображаються в його профілі.
